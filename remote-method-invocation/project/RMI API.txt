Remote Method Invocation (RMI)
用于实现远程过程调用的应用程序编程接口API
- 客户机上运行的程序可以调用远程服务器上的对象, 在网络环境中分布操作
- 依赖于接口, 通过传递一个接口来隐藏底层的实现细节
